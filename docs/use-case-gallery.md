# Use Case Gallery – AI in Just Energy Transitions
[Home](index.md) • [TRUST Matrix](trust-matrix.md) • [AI Ethics Principles](ai-ethics-principles.md) • [Use Case Gallery](use-case-gallery.md)

This gallery showcases documented AI use cases in Africa’s energy sector, using the **AIG4JETA Use Case Template** and the **TRUST Matrix**.

Each use case includes:

- Context and problem statement  
- AI solution description  
- Mapping to the TRUST Matrix and AI Ethics Principles  
- Governance, stakeholder engagement, and lessons learned  

---

## UC-001 – AI-based Load Forecasting for Rural Mini-Grids (East Africa)

- **ID:** UC-001  
- **Title:** AI-based Load Forecasting for Rural Mini-Grids in East Africa  
- **Goal:** Improve reliability and reduce diesel use through better demand forecasting.  
- **Key actors:** Mini-grid operator, community cooperative, rural households and SMEs.  

👉 **Read the full use case:**  
[`use-cases/uc-001-mini-grid-load-forecasting.md`](../use-cases/uc-001-mini-grid-load-forecasting.md)

## UC-003 – AI-based Planning for Grid-Connected Renewable Integration

- **ID:** UC-003  
- **Title:** AI-based Planning for Grid-Connected Renewable Integration in an African Power System  
- **Goal:** Support national or regional planners to integrate higher shares of solar and wind while maintaining reliability, affordability, and energy justice.  
- **Key actors:** System operator, planning authority, regulators, IPPs, communities, and energy justice advocates.

## Future Use Cases

Additional use cases will be added over time, for example:

- Loss detection and reduction in urban distribution networks  
- AI-supported tariff design and affordability analysis  
- Renewable integration and grid stability tools (operational, not just planning)  
- Energy access planning and last-mile electrification support  

Once documented, each will receive a unique ID (e.g. UC-002, UC-004) and will be listed here.

## How to Contribute a New Use Case

1. Copy the **Use Case Template:**  
   [`use-cases/use-case-template.md`](../use-cases/use-case-template.md)

2. Fill it in for your project or pilot.

3. Open an issue or pull request in the GitHub repo with your draft.

4. The AISESA AI Working Group will review and, once agreed, add it to the Use Case Library and this gallery.
