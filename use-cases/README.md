# Use Case Library

This folder contains real-world examples of AI applications in the African energy sector, each documented using a structured template and mapped to governance requirements.

---

## Purpose

The use case library serves to:
- **Ground frameworks in reality**: Ensure TRUST Matrix and ethics principles address actual challenges
- **Enable peer learning**: Share successes, failures, and lessons across organizations
- **Build evidence base**: Demonstrate diversity of AI applications and governance needs
- **Support training**: Provide concrete examples for capacity-building programs

---

## How to Contribute a Use Case

1. **Copy the template**: Use [`TEMPLATE-use-case-description.md`](TEMPLATE-use-case-description.md)
2. **Fill in sections**: Provide as much detail as comfortable (can be anonymized)
3. **Submit**: Create a pull request or email to working group chair
4. **Review**: Working group will review, provide feedback, and integrate

See [`CONTRIBUTING.md`](../CONTRIBUTING.md) for detailed guidance.

## Use Case Categories

As the library grows, we'll organize use cases by:

**AI Application Type**:
- Demand forecasting
- Grid optimization/stability
- Predictive maintenance
- Renewable energy forecasting
- Trading/pricing optimization
- Customer service automation
- Energy access planning
- Fraud detection
- Resource planning

**TRUST Profile** (once assessed):
- High-Trust (Levels 4-5 across dimensions)
- Medium-Trust (Levels 2-3)
- Lower-Trust (Levels 1-2)
- Mixed profiles

**Sector Focus**:
- Generation (renewable / fossil)
- Transmission
- Distribution
- Access/Off-grid
- Efficiency

**Geographic Scope**:
- National
- Regional
- Local/Community

## Anonymization & Confidentiality

We recognize that some organizations may wish to share lessons without identifying themselves or disclosing proprietary information.

**Options**:
- **Fully identified**: Organization name, detailed technical information
- **Partially anonymized**: Organization type and region, general technical approach
- **Fully anonymized**: Generic description focused on governance lessons

All options are valuable. Contact the working group if you have questions about what to share.
